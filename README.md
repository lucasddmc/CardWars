# Card Wars (macOS Fork)

This is a fork of [shishkabob27/CardWars](https://github.com/shishkabob27/CardWars) — a Unity port of the mobile game *Adventure Time: Card Wars* — created to add **macOS support** to the original Windows-only build. The upstream project was archived in March 2024.

This is an unofficial, non-commercial fan project. See [LICENSE](LICENSE) for license terms and the IP notice covering the underlying game assets.

## Building from source

Card Wars uses Unity 2017.4.40f1. No other dependencies are required.

For macOS builds, install Unity 2017.4.40f1 with the **Mac Build Support (Mono)** module from the [Unity Archive](https://unity.com/releases/editor/archive). The Editor runs on Apple Silicon Macs via Rosetta 2.
